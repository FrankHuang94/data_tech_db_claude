- **Cloud services layer** — Snowflake's shared, multi-tenant layer that handles metadata, query optimization, security and transactions above the compute clusters. (ch26)
- **Pruning** — Skipping data files or partitions whose stored min/max metadata proves they cannot match a query's filter. (ch26)
- **Result cache** — Snowflake's store of recent query results, returned without starting compute when the underlying data has not changed. (ch26)
- **Fail-safe** — Snowflake's seven-day recovery period after Time Travel expires, during which only Snowflake support can restore data. (ch26)
- **Zero-copy cloning** — Creating a copy of a table or database by copying metadata pointers to immutable files rather than the data itself. (ch26)
- **Snowflake credit** — Snowflake's unit of compute consumption; warehouses burn credits per second by size, and the dollar price per credit depends on edition and region. (ch26)
- **Capacity contract** — A prepaid or committed agreement to consume a dollar amount of a vendor's usage units over a term, recognised as revenue only when consumed. (ch26)
- **Remaining performance obligations** — Contracted revenue a company has not yet recognised; for consumption vendors, signed but unconsumed commitments. (ch26)
- **Efficiency headwind** — Revenue a consumption-priced vendor loses when its own performance improvements cut what customers pay for the same work. (ch26)
- **Stock-based compensation** — Employee pay in equity, expensed under GAAP but excluded from most companies' non-GAAP profit measures. (ch26)
- **Snowpark** — Snowflake's runtime and APIs for running Python, Java and Scala code inside the platform. (ch26)
- **Hybrid table** — Snowflake's row-oriented table type (Unistore) for low-latency, transactional reads and writes alongside analytics. (ch26)
- **External volume** — A Snowflake object that points Iceberg tables at customer-owned object storage, including S3-compatible stores. (ch26)
- **Apache Polaris** — The open-source Iceberg REST catalog Snowflake created in 2024 and donated to Apache, a top-level project since 2026. (ch26)
- **Horizon Catalog** — Snowflake's proprietary governance, discovery and catalog layer, which also exposes an Iceberg REST endpoint to outside engines. (ch26)
- **Cortex AI** — Snowflake's hosted LLM functions, search and agent services that run next to governed data and bill in credits. (ch26)
- **Snowflake CoWork** — Snowflake's agent assistant for business users, renamed from Snowflake Intelligence in June 2026. (ch26)
- **Openflow** — Snowflake's Apache NiFi-based ingestion service, built from the 2024 Datavolo acquisition. (ch26)
- **Gen2 warehouse** — Snowflake's newer generation of virtual warehouses with faster hardware and software for the same credit-based billing. (ch26)
