- **Open core** — a business model that gives away an open-source engine and sells proprietary enterprise features on top. (ch38)
- **Open Source Definition** — the Open Source Initiative's ten criteria a licence must meet to be called open source, including no discrimination against users or fields of use. (ch38)
- **Permissive license** — an open-source licence such as Apache 2.0, MIT or BSD that allows reuse, including inside proprietary products and hosted services, with minimal conditions. (ch38)
- **Copyleft** — a licence condition requiring that derivative works be distributed under the same licence terms. (ch38)
- **AGPL** — the GNU Affero General Public License, an OSI-approved copyleft licence whose source-sharing duty also applies when software is offered over a network. (ch38)
- **Source-available license** — a licence that publishes source code but restricts its use, typically barring competing hosted services; not open source under the OSI definition. (ch38)
- **SSPL** — MongoDB's Server Side Public License (2018), which requires anyone offering the software as a service to publish the source of their whole service stack. (ch38)
- **Business Source License** — a source-available licence (BSL) that restricts certain production uses until a change date, after which the code converts to an open-source licence. (ch38)
- **Elastic License 2.0** — a short source-available licence (ELv2) that permits internal use but bars offering the software as a managed service or circumventing licence keys. (ch38)
- **Fair source** — a label, promoted by Sentry from 2024, for source-available licences that convert to open source after a fixed delay, such as the two-year Functional Source License. (ch38)
- **Relicensing** — changing the licence that applies to future versions of a project, usually to restrict competitors such as cloud providers. (ch38)
- **Software fork** — an independent project started from a copy of another project's code, typically its last permissively licensed release. (ch38)
- **Contributor license agreement** — a contract in which contributors grant a project owner rights over their code, which is what lets the owner relicense later. (ch38)
- **Project Management Committee** — the group of individuals, elected on merit, that governs an Apache Software Foundation project. (ch38)
- **Valkey** — the Linux Foundation's BSD-licensed fork of Redis 7.2.4, created in March 2024. (ch38)
- **Open weights** — publicly released AI model parameters, whose licence may or may not meet an open-source definition. (ch38)
- **Apache Polaris** — an open-source Iceberg REST catalog donated by Snowflake in 2024 that became an Apache top-level project in 2026. (ch38)
- **Unity Catalog** — Databricks' governance catalog for data and AI assets, with an Apache 2.0 open-source server hosted at LF AI & Data since 2024. (ch38)
