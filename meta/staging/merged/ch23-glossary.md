- **Real-time analytics** — Sub-second analytical queries over data that is seconds old, served at high concurrency to apps, users or agents. (ch23)
- **User-facing analytics** — Analytics embedded in a product and queried by its end users or customers rather than by internal analysts. (ch23)
- **Tail latency** — The latency of the slowest requests (e.g., the 99th percentile, p99), which governs how responsive a system feels. (ch23)
- **Columnar replica** — A column-format copy of row-store data, kept current by replication, used to serve analytical reads in HTAP systems (e.g., TiFlash). (ch23)
- **MergeTree** — ClickHouse's core table engine: sorted, immutable columnar parts written per insert and merged in the background. (ch23)
- **Sparse primary index** — An index holding one entry per block of rows (not per row), small enough to stay in memory. (ch23)
- **Granule** — ClickHouse's smallest unit of data read, 8,192 rows by default, addressed by one sparse-index entry. (ch23)
- **SharedMergeTree** — ClickHouse Cloud's MergeTree variant that keeps all table data on shared object storage with stateless replicas. (ch23)
- **Materialized view** — A stored query result kept up to date as source data changes; in ClickHouse, an insert trigger that writes pre-aggregated rows. (ch23)
- **Segment** — In Apache Druid and Pinot, an immutable, time-partitioned, indexed columnar data file. (ch23)
- **Star-tree index** — Apache Pinot's index that pre-aggregates metrics over chosen combinations of dimensions for predictable low latency. (ch23)
- **Converged index** — Rockset's design of storing every field in a row index, a column index and a search index at once. (ch23)
- **In-process database** — A database engine that runs as a library inside the application's process, with no separate server (e.g., SQLite, DuckDB). (ch23)
- **Small data** — The thesis that most analytical queries touch data small enough to process on one machine. (ch23)
- **Upsert** — An operation that inserts a row or, if a row with the same key exists, updates it. (ch23)
