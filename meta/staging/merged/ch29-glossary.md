- **SSPL** — MongoDB's Server Side Public License (2018), which requires anyone offering the software as a service to publish the source of their whole service stack. (ch29)
- **AGPL** — The GNU Affero General Public License, an OSI-approved copyleft licence whose source-sharing duty also applies when software is offered over a network. (ch29)
- **Business Source License** — A source-available licence (BSL) that restricts certain production uses for a set period, after which the code converts to an open-source licence. (ch29)
- **Source-available license** — A licence that publishes source code but restricts its use, typically barring competing hosted services; not open source under the OSI definition. (ch29)
- **Postgres extension** — An add-on module that adds data types, index methods or functions to PostgreSQL without forking the core engine. (ch29)
- **pgvector** — The open-source PostgreSQL extension for storing embeddings and running exact or approximate nearest-neighbour search. (ch29)
- **Database branching** — Creating an instant copy-on-write clone of a database at a point in its history, for testing or agent sandboxes. (ch29)
- **Scale to zero** — Shutting down a database's compute when it is idle so that it costs almost nothing until the next query. (ch29)
- **Term license** — A time-limited software licence (for example MongoDB Enterprise Advanced) whose licence portion is recognised as revenue upfront under ASC 606. (ch29)
- **Agent memory** — Persistent state that an AI agent stores and retrieves across sessions, often kept in an operational or key-value database. (ch29)
- **Support annuity** — Recurring maintenance revenue earned on an installed base of perpetual licences, such as Oracle's database support. (ch29)
- **Atlas** — MongoDB's fully managed, consumption-priced database service on AWS, Azure and Google Cloud. (ch29)
- **Enterprise Advanced** — MongoDB's self-managed subscription offering with management tooling, security features and support. (ch29)
- **Vitess** — The open-source MySQL sharding system built at YouTube, CNCF-graduated in 2019 and commercialised by PlanetScale. (ch29)
- **Semantic cache** — A cache that returns a stored LLM answer when a new prompt is close in meaning to an earlier one, matched by embedding similarity. (ch29)
