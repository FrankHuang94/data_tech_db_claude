- **System of record** — The application whose data is the authoritative version of a business fact, such as CRM for customers or ERP for invoices. (ch34)
- **System of intelligence** — The layer that combines data across systems of record so analytics and AI agents can decide and act. (ch34)
- **Write-back** — An agent or tool changing data in the source application, subject to that application's business rules and approvals. (ch34)
- **Data Cloud** — Salesforce's customer-data and lakehouse layer behind Agentforce, reportedly renamed Data 360 in 2025. (ch34)
- **Agentforce** — Salesforce's AI agent platform, launched in 2024 and priced per conversation and later per action. (ch34)
- **Business Data Cloud** — SAP's data service (2025) that packages application data as semantic data products, with Databricks embedded. (ch34)
- **Workflow Data Fabric** — ServiceNow's data layer combining RaptorDB, zero-copy connectors and a catalog for its agents. (ch34)
- **Master data management** — Maintaining one authoritative record for core entities such as customers, products and suppliers across systems. (ch34)
- **Flex Credits** — Salesforce's consumption currency for Agentforce, priced per agent action. (ch34)
- **Seat-based pricing** — Charging per named user, which exposes software vendors when AI agents replace human users. (ch34)
