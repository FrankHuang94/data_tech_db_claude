- **Ontology** — A governed model of business objects, their properties, the links between them and the actions allowed on them; Palantir Foundry's core abstraction. (ch31)
- **Write-back** — An analytical or AI application changing data in the source system (for example ERP), rather than only reading it. (ch31)
- **Digital twin** — A live software model that mirrors physical or business entities and can push changes back to them. (ch31)
- **MergeTree** — ClickHouse's core table engine: sorted, immutable columnar parts written per insert and merged in the background. (ch31)
- **In-process database** — A database engine that runs as a library inside the application's process, with no separate server (e.g., SQLite, DuckDB). (ch31)
- **Icehouse** — Starburst's name for a lakehouse built on the Trino engine and Apache Iceberg tables on object storage. (ch31)
- **Open core** — A business model in which the core software is free and open source and the vendor charges for proprietary features, support or a managed service. (ch31)
- **Take-private** — The purchase of a listed company, usually by private-equity firms, after which its shares are delisted. (ch31)
- **OEM** — Original equipment manufacturer arrangement: one vendor embeds and resells another vendor's product inside its own offering. (ch31)
- **Hybrid data platform** — A single data software stack designed to run both on-premises and in public clouds with the same tools and governance. (ch31)
