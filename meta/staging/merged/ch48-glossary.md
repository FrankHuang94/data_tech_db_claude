- **Listen-for note** — in the Ch 48 question bank, a short description of what a strong answer to a question contains, used as a scoring key after the meeting. (ch48)
- **Revenue run-rate** — annualized recent revenue (quarter times four or month times twelve); not audited annual revenue. (ch48)
- **Net revenue retention** — revenue this period from a cohort of customers divided by the same cohort's revenue a year earlier. (ch48)
- **Remaining performance obligations** — contracted revenue not yet recognised; under consumption contracts it converts only as customers consume. (ch48)
- **DBU** — Databricks Unit, the metered unit of Databricks compute consumption. (ch48)
- **Snowflake credit** — Snowflake's unit of compute consumption, priced by edition and region. (ch48)
- **Open table format** — a metadata layer and commit protocol (Iceberg, Delta, Hudi) that turns files on object storage into a transactional table. (ch48)
- **Technical catalog** — the on-path service that resolves table names, arbitrates commits and enforces access. (ch48)
- **Credential vending** — a catalog issuing short-lived, table-scoped storage credentials to an authorized engine. (ch48)
- **Change data capture** — reading a database's log to emit each committed change as an event. (ch48)
- **Zero-ETL** — a vendor-operated replication pipeline, usually CDC, that the customer does not build. (ch48)
- **Permission-aware retrieval** — retrieval that filters results by the requesting user's access rights before content reaches a model. (ch48)
- **Model Context Protocol** — an open standard for connecting AI agents to tools and data sources. (ch48)
- **Lethal trifecta** — an agent with private-data access, exposure to untrusted content and a way to send data out. (ch48)
- **Text-to-SQL** — generating SQL queries from natural-language questions. (ch48)
- **Golden set** — a curated, labelled set of questions and answers used to evaluate a model or retrieval system. (ch48)
- **Data security posture management** — tools that discover, classify and score risk on sensitive data across an estate. (ch48)
- **OpenSharing** — Databricks' open sharing protocol, used by storage partners to expose on-premises tables to Unity Catalog. (ch48)
- **Enterprise value** — equity value plus debt minus cash; the basis for EV/revenue multiples. (ch48)
- **Liquidation preference** — a preferred shareholder's right to be repaid before common holders in a sale. (ch48)
