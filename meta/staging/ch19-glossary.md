- **Chunking** — Splitting parsed documents into retrievable units, usually a few hundred to about a thousand tokens, with metadata attached. (ch19)
- **Hybrid search** — Running keyword (BM25) and dense-vector retrieval for the same query and merging the results. (ch19)
- **Reciprocal rank fusion** — A method for merging ranked lists that scores each item by the sum of 1/(k + rank) across lists, with k = 60 by convention (RRF). (ch19)
- **Bi-encoder** — A model that embeds queries and documents separately, so document vectors can be pre-computed and searched quickly. (ch19)
- **Cross-encoder** — A model that reads a query and a passage together and outputs one relevance score; accurate but too slow to run over a whole corpus. (ch19)
- **Reranker** — A second-stage model, usually a cross-encoder, that reorders a short list of retrieved candidates by relevance. (ch19)
- **HyDE** — Hypothetical Document Embeddings: retrieving with the embedding of an LLM-written hypothetical answer instead of the raw question. (ch19)
- **Agentic RAG** — Retrieval exposed as a tool that an AI agent calls repeatedly, refining queries and switching sources until it has enough evidence. (ch19)
- **GraphRAG** — Microsoft Research's 2024 approach that has an LLM extract an entity graph, cluster it into communities and pre-write summaries for answering corpus-wide questions. (ch19)
- **Knowledge graph** — A store of entities and typed relationships between them, queried by traversal. (ch19)
- **Ontology** — A governed model of an organisation's business objects, their properties, links and permitted actions, such as Palantir's Foundry Ontology. (ch19)
- **Lost in the middle** — The finding (Liu et al., 2023) that language models use information at the start and end of long inputs better than information in the middle. (ch19)
- **Context rot** — The decline in model reliability as input length grows, even on simple tasks (Chroma, 2025). (ch19)
- **Prompt caching** — Reusing an already-processed prompt prefix across requests at a discounted token price and lower latency. (ch19)
- **Context engineering** — Selecting, compressing and ordering everything that enters a model's context window: instructions, tools, memory, history and retrieved documents. (ch19)
- **KV cache** — The attention keys and values a transformer stores for tokens already processed, so they need not be recomputed; it grows linearly with context length. (ch19)
- **Context precision** — A retrieval metric for the share of retrieved passages that are relevant, weighted toward the top ranks. (ch19)
- **Faithfulness** — A RAG metric for whether every claim in an answer is supported by the retrieved context. (ch19)
- **LLM-as-judge** — Using a language model to grade another model's outputs against a rubric or reference. (ch19)
- **Needle in a haystack** — A long-context test that hides one fact in filler text and asks the model to retrieve it; it measures lookup rather than reasoning. (ch19)
