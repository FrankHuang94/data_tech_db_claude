- **Hyperscaler** — A cloud provider operating at global datacenter scale, chiefly AWS, Microsoft Azure and Google Cloud, often with Oracle OCI included. (ch28)
- **Committed spend** — A multi-year contract in which a customer promises a minimum spend with a cloud provider in exchange for discounts, with any shortfall still billed. (ch28)
- **MACC** — Microsoft Azure Consumption Commitment, Microsoft's committed-spend contract, which eligible Azure Marketplace purchases can draw down. (ch28)
- **EDP** — AWS Enterprise Discount Program, AWS's historical name for its committed-spend discount contract. (ch28)
- **Cloud marketplace** — A hyperscaler storefront where customers buy third-party software on their cloud bill. (ch28)
- **Marketplace drawdown** — Counting purchases made through a cloud marketplace against the customer's committed spend with that cloud. (ch28)
- **First-party service** — A partner's product that the cloud provider itself sells, bills and supports, such as Azure Databricks. (ch28)
- **Coopetition** — Competing and cooperating with the same company at the same time, as hyperscalers do with Databricks and Snowflake. (ch28)
- **S3 Tables** — AWS's managed Apache Iceberg tables stored in S3 "table buckets", with automatic compaction and snapshot clean-up. (ch28)
- **S3 Vectors** — AWS's vector storage and similarity-search capability built into S3, GA at re:Invent 2025. (ch28)
- **OneLake** — Microsoft Fabric's single tenant-wide logical data lake that stores tables as Delta/Parquet. (ch28)
- **OneLake shortcut** — A pointer that mounts data from ADLS, S3, Google Cloud Storage or other stores into OneLake without copying it. (ch28)
- **Microsoft Fabric** — Microsoft's SaaS analytics suite (pipelines, Spark, warehouse, real-time, Power BI) built on OneLake and capacity pricing. (ch28)
- **BigQuery** — Google Cloud's serverless data warehouse, descended from Google's internal Dremel engine. (ch28)
- **Knowledge Catalog** — Google Cloud's governance and metadata catalog, renamed in 2026 from Dataplex Universal Catalog. (ch28)
- **Exadata** — Oracle's engineered database hardware that pushes SQL filtering into storage servers connected by RDMA. (ch28)
- **Database at hyperscaler** — Oracle's model of running Exadata-based Oracle Database inside Azure, Google Cloud and AWS datacenters, sold through the host cloud (Oracle Database@Azure, @Google Cloud, @AWS). (ch28)
- **Remaining performance obligations** — Contracted revenue a company has not yet recognised, i.e. its reported backlog. (ch28)
- **Take-or-pay** — A supply contract in which the buyer pays for a committed volume whether or not it takes delivery. (ch28)
- **Integrated device manufacturer** — A semiconductor company that both designs and fabricates its chips; used in the atlas as an analogy for hyperscalers. (ch28)
- **Fabless** — A semiconductor company that designs chips but rents manufacturing capacity; used in the atlas as an analogy for Databricks and Snowflake. (ch28)
- **Slot** — BigQuery's unit of query compute capacity, billed on reservations or consumed on demand. (ch28)
